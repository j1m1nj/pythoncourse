# 앱 이름: 책읽자 지민아

## 왜 만드나
독서 기록을 체계화하는 앱을 원합니다.
기록한 날짜, 책 제목, 페이지 수, 메모를 정리하고 싶습니다.
이를 한곳에 모아 빠르게 파악할 수 있는 앱을 만들고 싶습니다.

## 기록 항목
- 날짜: 기록한 날짜
- 항목: 책 제목
- 분류: 작가
- 숫자: 페이지 수
- 메모: 기록 내용 (요약, 질문, 비판 등)
